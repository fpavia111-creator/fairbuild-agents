# Fairbuild Delivery Tickets fixtures

Everything here is fictional: suppliers (Sample Ready Mix, Sample Lumber Supply, Example Block Co), tickets, invoices and prices.

- `tickets.csv`: six signed delivery tickets. DT-506 has not been invoiced.
- `invoices.csv`: six invoice lines. SRM-7702 bills 38 yards against a 36-yard ticket; SL-88120 bills studs at 6.75 against an agreed 6.50; SL-88341 says 4,900 for 200 at 24.00; SL-88342 bills ticket DT-504 a second time; EBC-310 has no ticket (DT-505 matches it).
- `prices.csv`: the agreed prices.
