# Fairbuild Timecards fixtures

Everything here is fictional: workers, ids, jobs and hours.

- `timecards.csv`: ten entries. Casey Sample charged 24-102 on the 10th while assigned to 24-101; Riley Test charged 7 hours to 23-095, a closed job, on a 16-hour day; Morgan Example charged cost code 05-120, which 24-101 has no budget for, and entered the 12th twice; Jordan Example worked Saturday the 14th.
- `assignments.csv`, `jobs.csv`, `budget.csv`: who was assigned where, which jobs are closed, and the budget cost codes.
- `exports/sage300-timecards.csv`: three entries as a Sage 300 timecard export.
